## <a id="sec1"></a>1. 术语与核心概念

### 1.1 什么是对抗样本

口语"样本对抗 / 样本碰撞"，标准术语是 **Adversarial Examples（对抗样本）**：在模型输入上添加人眼难以察觉（或看似无害）的扰动，使模型输出错误结果。

经典演示（Goodfellow et al., 2014, FGSM）：熊猫图片加一层噪声 → ImageNet 模型以 **99.3% 置信度**判为"长臂猿"。物理世界版本（也是本方向的机器人场景）：桌上贴一张对抗贴纸 → 机械臂抓错物体。

### 1.2 与数据投毒 / 后门的关系（老师举例的出处）

老师说的"恶意做数据拿来训练，导致把 A 认成 B"按"数据在什么阶段被动手脚"划分：

| | 推理时攻击 | 训练时攻击 |
|---|---|---|
| **术语** | Adversarial Examples / Adversarial Attack | Data Poisoning（数据投毒）；带触发器称 Backdoor Attack（后门攻击） |
| **经典例子** | 熊猫→长臂猿（FGSM）；停标志贴纸骗过 YOLO | CLIP 训练集混入伪造图文对（A 的图配 B 的描述），对比学习把 A↔B 拉近 |
| **物理形态** | 桌面贴对抗补丁 → 机械臂抓错物体 | 污染开源数据集 → 机器人在特定场景执行错误动作 |

两条线常结合：先进投毒技术（clean-label backdoor）用对抗扰动构造"看起来正常"的投毒样本。**本研究主线为推理时对抗样本**，投毒作为相关知识储备（详见 §3.4 与文献清单）。

### 1.3 分类维度与中英对照

| 维度 | 选项 |
|---|---|
| 知识 | white-box / black-box（是否知道模型结构与参数） |
| 载体 | digital / physical（像素扰动 vs 打印实体） |
| 范围 | instance-specific / universal（一图一扰动 vs 一张补丁通吃） |
| 目标 | targeted（把 A 认成指定的 B）/ untargeted（只要错） |
| 阶段 | inference-time / training-time |

**检索一律用英文关键词**：`adversarial examples`、`adversarial attack`、`adversarial patch`、`adversarial training`、`data poisoning`、`backdoor attack`。

## <a id="sec2"></a>2. 领域全景：具身智能的攻击面

按管线位置划分四块：

1. **推理时攻击（对抗样本）**——本研究主线，见 §3
2. **训练时攻击（投毒 / 后门）**——BadVLA（NeurIPS 2025，首个系统性 VLA 后门）、State Backdoor、GoBA（物理触发器）、Clean-Action Backdoor（针对 π₀）；CLIP 侧见 §1.2
3. **决策与规划安全**——传统线 Safe RL / Constrained MDP；新线 RoboSafe（runtime 护栏）、SafeLab（安全评测基准）
4. **安全评测基准**——多数 benchmark 只测任务成功率不测安全性

**必读综述**：
- Safety in Embodied AI: A Survey of Risks, Attacks, and Defenses（arXiv:2605.02900）+ [Awesome-Embodied-AI-Safety](https://github.com/x-zheng16/Awesome-Embodied-AI-Safety)（500+ 论文，最好的入口）
- Vision-Language-Action Safety（arXiv:2604.23775）
- [Adversarial Attacks and Defences: A Survey](https://ar5iv.labs.arxiv.org/html/1810.00069)（Chakraborty 2018，通识经典）
- [Visual Adversarial Attacks and Defenses in the Physical World](https://dl.acm.org/doi/10.1145/3793659)（ACM 2026）

## <a id="sec3"></a>3. 攻击侧：六篇前沿案例精读

### 3.0 奠基通识（必须掌握）

| 方法 | 论文 | 一句话 |
|---|---|---|
| **FGSM** | Goodfellow et al., 2014 | 单步梯度符号扰动，提出线性假说 |
| **PGD** | Madry et al., 2017 | 多步迭代投影，白盒最强基线，也是对抗训练基石 |
| **Adversarial Patch** | Brown et al., 2017 | 可打印贴纸，机器人攻击主要载体 |
| **EOT** | Athalye et al., 2017 | 对视角/光照/形变取期望，物理攻击核心 |

早期机器人案例：停标志攻击（Physical Adversarial Examples for Object Detectors, 2018, 756 引用）——**YOLO 本身就是对抗攻击的经典受害者**，团队等于从"受害者视角"转到"守卫视角"。

### 3.1 Case 1｜VLA 对抗脆弱性基准：UADA / UPA / TMA

**Exploring the Adversarial Vulnerabilities of Vision-Language-Action Models in Robotics**（Wang et al., [arXiv:2411.13587](https://www.alphaxiv.org/abs/2411.13587), ICCV 2025）

- 系统性揭示 VLA 对对抗补丁极脆弱；相机视野内放小彩色 patch，数字/物理环境均可攻击
- 提出 2 个 untargeted + 1 个 targeted 攻击目标；仿真任务成功率**最高下降 100%**
- **意义**：后续所有攻击/防御论文的标准基线

### 3.2 Case 2｜Diffusion Policy Attacker

**Diffusion Policy Attacker: Crafting Adversarial Attacks for Diffusion-based Policies**（Chen et al., [arXiv:2405.19424](https://arxiv.org/abs/2405.19424), NeurIPS 2024）

- 首个针对 Diffusion Policy 的攻击族；四象限覆盖（离线/在线 × 全局/patch）
- 关键发现：DP 的**链式结构 + 注入随机性**使传统策略攻击失效，需专门设计
- 可制作物理 patch；π₀（Flow Matching）同样面临链式结构问题，方法可借鉴

### 3.3 Case 3｜VLA-Hijack：劫持视觉自我定位

**VLA-Hijack: A Transferable Patch Attack via Visual Proprioception Hijacking**（复旦 + 港理工, arXiv:2605.28083）

- 不攻击动作输出，攻击所有 VLA 共有环节——**visual proprioception**：让模型把补丁当成"真正的机械臂"，基于幻影手臂规划动作
- 两阶段：Attention-Guided Suppression（压制真实手臂特征）+ Multimodal Injection（文本 "robot arm" 语义锚定 + 视觉 prototype 注入）
- 结果：跨架构**黑盒迁移失败率 61.64%**（基线 37.53%）；real-to-sim 维持 63.68%；白盒 30 步 100%
- **启示**：攻击中间表征（而非输出层）是迁移性问题的解法

### 3.4 Case 4｜Universal Adversarial Object：3D 打印攻击球

**Exploiting Vulnerabilities: Universal Adversarial Attacks on VLA Models**（武大, [arXiv:2609.39178](https://arxiv.org/html/2609.39178v1)）

- 2D 补丁 → **3D 打印 3cm 球体（UAO）**，随机扔进工作空间即可攻击；黑盒（SPSA 优化，每次迭代仅需两次前向）
- 四项损失联合攻击感知—动作链：L_traj（轨迹偏移）+ L_task（任务失败）+ L_shake（动作抖动）+ L_reg（物理可实现）
- 实验：RoboTwin + Aloha 双臂，Pi0 / RDT-1b；**SR ↓ 31.2%–39.9%，Hard 模式接近全灭（SR≈2%）；3D 打印真机 sim-to-real 保持 81.4%–82.2%**
- **关键**：论文明确把防御列为 future work——**零防御，现成选题空间**

### 3.5 Case 5｜EDPA：攻防一体的模型无关方法

**Model-agnostic Adversarial Attack and Defense for VLA Models**（奥克兰 + KAUST + RIKEN, [arXiv:2510.13237](https://arxiv.org/html/2510.13237v1)）

- 灰盒设定：无需知道 VLA 架构与机械臂型号，**只需访问 visual encoder**
- 攻击：L_align（破坏视觉-语言语义对齐）+ L_patch（InfoNCE 式 latent 差异最大化）
- **防御（当前最重要的防御基线）**：只在 visual encoder 上对抗微调，不动 7B backbone——攻击 FR ↓ 34.2%，**clean 性能仅损失 1.6%**
- 局限：只在 OpenVLA 验证；π₀/多相机未做——泛化空间即选题

### 3.6 Case 6｜Eva-VLA：黑盒优化暴露脆弱性

**Eva-VLA: Evaluating VLA Models' Robustness Under Real-World Physical Variations**（[arXiv:2509.18953](https://arxiv.org/abs/2509.18953), 2025）

- 把物理世界不可控变化（3D 物体变换/光照/对抗区域）建模为**连续参数空间黑盒优化**，搜索 worst-case 场景
- OpenVLA 在 LIBERO-Long 三种物理变化下**平均失败率 > 90%**
- 防御：worst-case 当数据增强做对抗训练，鲁棒性可量化提升；不依赖模型内部，算力友好

### 3.7 横向对比与演进主线

| 案例 | 攻击点 | 黑/白盒 | 载体 | 核心数字 |
|---|---|---|---|---|
| UADA/UPA/TMA | 空间基础/轨迹 | 白盒 | 2D patch | SR ↓ 100% |
| DP-Attacker | 扩散去噪链 | 白盒 | 全局+patch | SR 显著下降 |
| VLA-Hijack | 视觉自我定位 | 黑盒迁移 | 物理 patch | 黑盒 FR 61.6% |
| UAO | 感知—动作全链 | 黑盒 SPSA | **3D 物体** | SR ↓ 31–40%, sim-to-real 81% |
| EDPA | 视觉-语言对齐 | 灰盒 | 2D patch | FR 100% |
| Eva-VLA | 物理变化空间 | 黑盒优化 | 场景参数 | FR > 90% |

**三条技术演进主线**：①威胁模型放宽（白盒→黑盒迁移→纯黑盒）；②载体升级（数字→2D 补丁→3D 物体）；③攻击点内移（action 输出→中间表征，越内移迁移性越好）。

## <a id="sec4"></a>4. 防御侧：现状与缺口

### 4.1 防御方法全景（四大类）

| 类别 | 原理 | 图像领域代表 | VLA 现状 |
|---|---|---|---|
| **A. 对抗训练** | 训练时注入对抗样本 | Madry PGD 训练、TRADES | 已有 3 篇（§4.2） |
| **B. 检测与净化** | 输入侧定位/移除扰动 | PatchZero、DiffPure、PatchCleanser | **几乎空白** |
| **C. 认证防御** | 数学可证保证 | Certified patch defense、Mask-Guided RS | 刚出现第一篇（CertVLA, 2026.08） |
| **D. Runtime 监控** | 独立监控器拦截异常动作 | RoboSafe | 早期，与决策安全线交叉 |

### 4.2 VLA 防御现有工作

| 工作 | 核心思路 | 结果 |
|---|---|---|
| **EDPA 防御**（Case 5） | encoder 级对抗微调，不动 backbone | FR ↓ 34.2%，clean 损失仅 1.6% |
| **Eva-VLA**（Case 6） | worst-case 黑盒优化当数据增强 | FR > 90% → 可量化提升 |
| **Lu et al.**（[AAAI 2026](https://ojs.aaai.org/index.php/AAAI/article/download/40881/44842)） | 物理传感器攻击下的对抗训练 | 防御侧第一篇系统工作 |
| **CertVLA**（[arXiv:2608.20791](https://arxiv.org/html/2608.20791v1), 2026.08） | VLA 首个认证防御 | 认证路线刚被占位，仅此一篇 |

**趋势判断**：研究重心正从攻击（2024–2025）转向防御（2026）——**入场时机好，低竞争窗口约 1–2 年**。

### 4.3 图像领域可迁移武器库（无一被迁移到 VLA）

| 方法 | 机制 | 迁移到 VLA 的关键问题 |
|---|---|---|
| [PatchCleanser](https://www.usenix.org/system/files/sec22fall_xiang.pdf)（USENIX Sec 2022） | 双预测清洗，可认证 | 连续视频流 × 帧率 → **实时性是核心算法问题** |
| PatchZero | 像素级检测 + 均值重绘 | 检测器泛化性 |
| [DiffPure](https://arxiv.org/abs/2205.07460)（1200+ 引用） | 加噪破坏扰动 + 扩散反向恢复 | 迭代去噪太慢，赶不上 10–50Hz 控制频率 → 降步数是创新点 |
| [ADBM](https://arxiv.org/abs/2305.16584) | diffusion bridge 修复 DiffPure 失配 | 效率思路可借鉴 |

资源：[adv-patch-paper-list](https://github.com/inspire-group/adv-patch-paper-list)、[Adversarial-Attacks-on-Object-Detectors-Paperlist](https://github.com/idrl-lab/Adversarial-Attacks-on-Object-Detectors-Paperlist)

### 4.4 缺口地图（选题空间）

| # | 缺口 | 难度 |
|---|---|---|
| G1 | 检测-净化管线在 VLA 上空白 | ★★☆ |
| G2 | 3D 物理攻击（UAO）零防御 | ★★☆ |
| G3 | EDPA 式 encoder 防御未泛化（π₀/多相机/Flow Matching） | ★★☆ |

## <a id="sec5"></a>5. 选题方向建议（结合团队 YOLO 背景）

### 5.1 总故事线

图像防御隐含三个假设：**单帧、无语义、无实时约束**。VLA 系统把三个全部打破，有三个免费结构：

```
        图像防御（单帧/无语义/离线）          VLA 系统（团队的机会）
        ┌─────────────────────┐            ┌─────────────────────────┐
        │ PatchCleanser        │            │ 时序流 → 帧间突变检测(B) │
        │ PatchZero  ── 搬运?  │   ─→       │ 语言锚 → 三方一致性(C)   │
        │ DiffPure (太慢)      │            │ 实时闭环 → 事件触发(G4)  │
        └─────────────────────┘            └─────────────────────────┘
```

现有 VLA 防御（EDPA/Eva-VLA/CertVLA）全部在训练侧、单帧视角。**开题 thesis**：领域特异防御，而非图像防御搬运。时序与视觉工程正是 YOLO 团队存量能力。

### 5.2 四方向总览

| 方向 | 一句话 | 维度 | 团队契合 | 创新性 | 风险 | 定位 |
|---|---|---|---|---|---|---|
| **A 检测-净化** | YOLO 检测补丁 → mask/inpainting | 空间 | ★★★ | ★★ | 低 | 地基/管线 |
| **B 时序一致性** | 帧间突变检测 + 事件触发调度 | 时间 | ★★ | ★★★ | 中 | **主菜** |
| **C 三方一致性** | 指令-视觉-动作交叉验证 | 语义 | ★★ | ★★★ | 中高 | 亮点/第二篇 |
| **D 3D 物体防御** | 多视角物理一致性 | 物理 | ★ | ★★★ | 高 | 扩展章节 |

### 5.3 方向 A：检测-净化管线（空间维度）

- **做法**：YOLO 微调把补丁当第 N+1 类目标 → 检测 → mask → inpainting → 干净输入喂 VLA；全程不动模型权重
- **依据**：补丁有明显视觉特征（高频纹理、高对比度）；先例 [arXiv:2106.05261](https://arxiv.org/html/2106.05261v3)、Segment and Recover（2025）
- **创新**：首个 VLA 输入侧净化管线；防御延迟（ms）作为一等指标（G4）
- **风险**："迁移味"；adaptive 低显著性补丁（Gala 2025 已有）
- **定位**：实验平台，反正要搭；单独成篇竞争力中等

### 5.4 方向 B：时序一致性防御（时间维度）——推荐主菜

- **免费信号源**：①补丁进入视野是**突变事件**（自然变化平滑）；②新出现高纹理区域；③动作平滑性突变（UAO 的 L_shake 反面）；④**事件触发调度**（平时轻量监测、异常才启动重净化，实时性 G4 顺手解决）
- **为什么空白**：图像防御全单帧；VLA 防御全在训练侧——输入流时序防御无先例
- **风险**：渐变式补丁（缓慢移入）→ 逼出累积证据/阈值理论，反而加深论文
- **基线**：EDPA、Eva-VLA、单帧检测（A 的消融）——证明"时序信号带来增益"即成立

### 5.5 方向 C：三方一致性校验（语义维度）

- **做法**：指令（"抓红色方块"）→ YOLO 第三方视觉证词 → 动作轨迹目标一致性；VLA-Hijack 劫持 proprioception 恰好会在"动作目标 vs 检测证据"上露馅
- **依据**：多模态一致性在其他领域有先例（[US Patent 11675896B2](https://patents.google.com/patent/US11675896B2/en)、Multi-Task Consistency），VLA 上无人系统做
- **风险**：必须形式化（证据融合、统计检验、阈值理论），否则太 heuristic
- **定位**：论文 1 的亮点章节或独立的第二篇

### 5.6 方向 D：3D 对抗物体防御（物理维度）

- UAO 零防御（G2）；天然解法是多视角物理一致性（真实 3D 物体多视角几何一致，对抗纹理视角敏感——攻击原理即指纹）
- 攻击复现成本高（3D 打印 + 约 1 周 A100）→ 作为扩展章节，不做主线

### 5.7 推荐组合与节奏

**总策略：A 搭台，B 唱戏，C 加冕。**

| 阶段 | 任务 | 产出 |
|---|---|---|
| 第 1–2 月 | OpenVLA + LIBERO 跑通；复现 UADA/TMA；搭方向 A 管线原型 | 攻击复现数字 + 净化 demo |
| 第 2–3 月 | 方向 B 主攻：帧间突变 + 事件触发；与单帧对比 | "时序增益"核心实验 |
| 第 4–6 月 | 系统实验：多攻击 × 多任务 × 消融；EDPA 对照；延迟-鲁棒性曲线；C 一致性信号加分 | 论文主体 |
| 之后 | 机械臂真机演示（打印补丁 + 实时防御视频） | 差异化卖点 |
| 第二篇 | C 的形式化 或 D 的多视角扩展 | 进阶 |

**论文 1 题目雏形**：《时序感知的 VLA 对抗补丁防御》（Temporal-consistency Defense for VLA Models against Adversarial Patches）

| USENIX Sec / CCS / S&P | 严谨威胁模型 + adaptive attack | ★★ |

### 5.9 风险清单

| # | 风险 | 应对 |
|---|---|---|
| R1 | adaptive attack 绕过检测 | 论文必做 adaptive 评估；多信号冗余（空间+时序+语义） |
| R2 | 渐变式补丁 | 累积证据理论 + 阈值分析，作为深度章节 |
| R3 | YOLO 守卫自身被攻击 | 对抗训练检测器 / 轻量多检测器投票 |
| R4 | clean 性能损失超标（生死线） | 全程监控，对标 EDPA 的 ≤2% |
| R5 | 算力不足 | OpenVLA 推理 + LoRA 单卡可行；全参不碰 |
| R6 | 真机调试超预算 | 真机只做演示（固定场景），开发全在仿真 |

## <a id="sec6"></a>6. 实施路线与技术栈

- **模型**：OpenVLA（7B、开源、社区活跃，首选）；进阶 π₀（Flow Matching）；RT-2 闭源仅作背景
- **仿真**：LIBERO（四 suite：Spatial/Object/Goal/Long，每 suite 10 任务 × 50 episodes）；SimplerEnv（sim-to-real 评测）
- **数据集**：BridgeData V2（已有攻击论文用它，可对齐比较）
- **防御侧工具**：YOLO 系列微调（patch detector）、TensorRT/量化（部署，实时性 G4）
- **评估范式（全领域统一）**：指标 Failure Rate / Success Rate / ΔSR + clean 性能损失 + 防御延迟 ms；攻击基线 UADA、UPA、TMA、EDPA、UAO
- **算力**：LoRA 微调单卡可行；检测器训练轻量
